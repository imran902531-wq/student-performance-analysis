# Student Performance Analysis Using Python

## Project Overview
This project analyzes student study hours and marks using Python. It calculates basic statistics and visualizes the relationship between study hours and marks.

## Technologies Used
- Python
- Pandas
- Matplotlib

## Features
- Load student data from a CSV file
- Calculate average marks
- Identify highest and lowest marks
- Visualize study hours versus marks

## Sample Results
- Average marks: 69.12
- Highest marks: 94
- Lowest marks: 42

## Project Structure
- `data.csv` - Sample student dataset
- `analysis.py` - Python analysis code
- `study_hours_vs_marks.png` - Generated chart

## How to Run
Install dependencies:

`python -m pip install pandas matplotlib`

Run the program:

`python analysis.py`

## Dataset
This project uses sample data created for educational purposes.
